PlanWall Help

  • Saving settings (3 steps):
    1 · Save settings now (or Ctrl+S) — writes this board into this browser.
    2 · Save board file (JSON) (or Ctrl+Shift+S) — downloads a file for OneDrive / backup.
    3 · Load board file — open that JSON on another computer.
  • OneDrive auto-sync: File → Link sync folder… and pick a folder inside OneDrive (e.g. OneDrive\PlanWall). After that, Ctrl+S and Sync now write the board JSON into that folder automatically (Chrome/Edge). On another PC: open the HTML app → Load board file from the same OneDrive folder.
  • Sharing a board with the office: Use step 2, put the JSON on OneDrive, they open PlanWall and use step 3. Each browser also keeps its own autosave.
  • Sharing the app: Send this single HTML file. Open it in Chrome, Edge, or Firefox. (PDF previews need internet the first time so PDF.js can load.)
  • Add objects: Toolbar — mind maps, Kanban, notes, images, PDFs, presentation frames.
  • Select (V) / Pan (H): Arrow moves objects; Hand pans the canvas. Hold Space for temporary pan.
  • Mind map: Drag one node over another until it glows, release to connect. Right-click node or line to disconnect.
  • Kanban: + adds cards; double-click edits/deletes; drag cards between columns. Resize the column with handles.
  • Notes: Double-click to edit. Escape or click away to finish. Colors in Properties.
  • PDFs: Import for a sharp page preview. Use ‹ › in the card header to change pages. Enlarge the card for more detail.
  • Presentation frames: Place objects fully inside a frame, then click Presentation. Connection lines are included.
  • Markup layer: Pen, Line, Rect, Ellipse, Text, Eraser. 👁 Markup toggles visibility.
  • 📍 Pin: Numbered RFI/issue stamps for drawings. Double-click to edit. Listed in the project log when nothing is selected.
  • ✅ Decision: Stamp who/what/when. Collects in the project log.
  • 📅 Timeline: Pull-plan day strip (set start date and length in Properties).
  • 🔗 Link: Click two objects to connect any types. Double-click a line to jump to an endpoint. Right-click line to disconnect.
  • Templates: Construction pull plan, school, multi-family, teaching outlines.
  • Paste screenshot: Snipping Tool / Print Screen, then Ctrl+V on the board. Drag-and-drop image files also work.
  • Layers: Assign Design / Field / Owner / Temporary per object. Toggle layers in the right panel when nothing is selected.
  • Export Pack: Downloads a read-only HTML snapshot for emailing the office (pins, decisions, Kanban, notes).
  • Meeting mode: Timer bar + Capture → This week turns selected notes into Kanban cards.
  • Break into tasks / Pins → punch list: Quick actions in the Properties panel.
  • Bookmarks: Save the current view (name it Site plan, Budget, etc.). Jump from the right panel or chips under the minimap.
  • Lock: Properties checkbox freezes an object (no move/resize/delete) — useful for PDFs while marking up.
  • Export frame PNG: Select a Presentation Frame → Export frame as PNG.
  • Search: ⌕ then type; Enter jumps the camera to the first match.
  • Save as template: Set up a board → Templates → Save current board as template… It appears under My templates.
  • Pomodoro: Click the big time numbers to set any length (15, 17, 20, 25… minutes). Volume slider + mute control the alarm.
  • Boards: Click the board name chip (or File → Boards). Save board as… names and saves the current board. Click another board row (or Switch to) to change boards. + New empty board starts fresh. Copy objects: Ctrl+C / Ctrl+V between boards.
  • Kanban → Excel: Select a Kanban column → Ctrl+C → in Excel Ctrl+V. Pastes columns: Column, Card, Checklist item, Done.
  • Kanban → phone / print: Select a column → Properties → Export column · print / iPhone. Sends a simple HTML list you can text, email, open on an iPhone, or Print → Save PDF.
  • Navigate: ✋ Pan · middle-mouse · Space+drag · wheel zoom · 1–9 jump bookmarks · Ctrl+1…9 save bookmark slots · search Enter · Go to 0,0.
  • Coordinates: Properties X/Y are world position. Set spawn point marks where new items appear. Zero coords here makes the current view center (or spawn point) true 0,0 so numbers reset without moving the picture.
  • Zoom: Mouse wheel. Delete: Select + Delete/Backspace key.
  • Undo / Redo: Ctrl+Z undo · Ctrl+Y or Ctrl+Shift+Z redo (also toolbar buttons). Works for deletes, moves, markup, and most edits. Autosave runs in the background.
